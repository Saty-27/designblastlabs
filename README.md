# DESIGN BLAST LABS

> **Digital Experiences, Technology and Marketing Systems That Help Businesses Grow.**

Design Blast Labs is an integrated digital, creative, and technology agency based in Mumbai, India, serving ambitious enterprises across India, the US, and global markets.

---

## ⚡ Tech Stack & Architecture

- **Framework**: Next.js 14 (App Router) + TypeScript
- **Styling**: Tailwind CSS + Custom Industrial Editorial Design System
- **Icons**: Lucide React
- **Performance**: 100% Static Generation (SSG), Sub-1.2s Interaction Latency
- **SEO & Search Architecture**: Flat URL structure across 14 specialized disciplines, self-referencing canonicals, JSON-LD structured data (`LocalBusiness`, `Service`, `BreadcrumbList`, `FAQPage`), and automated XML sitemap generation.

---

## 🌐 Route Structure (Flat URL System)

- **Homepage & Hubs**:
  - `/` — Flagship Interactive Homepage
  - `/services` — Services Directory & Discipline Matrix
  - `/work` — Filterable Client Case Studies & Production Showcase
  - `/mumbai` — Mumbai Headquarters & Regional Practice Hub
  - `/new-york` — New York Regional Practice Hub

- **14 Specialized Disciplines** (Each with 3 Flat Pages: General, Mumbai, and New York):
  - `/<slug>` — Global discipline specification & benchmarks
  - `/<slug>-in-mumbai` — Local Mumbai strategy, in-person kickoffs & case studies
  - `/<slug>-in-new-york` — US ET morning overlap, overnight delivery & borough targeting
